# Forsaken Shores Mod 🏝️

> A new horizon for Unturned.

Forsaken Shores is an independent, non-commercial project based on the **Unturned 3.0 U3 SDK**, focused on creating a new survival experience centered around exploration, navigation, islands, zombies, and discovery.
